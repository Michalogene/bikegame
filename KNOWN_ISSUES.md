# Known issues

- Character and enemy models are procedural low-poly placeholders; animation fidelity remains below the visual reference.
- The authored Pine Ridge slice is dense but still much smaller than the intended final county.
- Terrain digging updates the visual heightfield and navigation cost, but placed structures do not yet conform after later excavation beneath them.
- Vehicle driving is not implemented in the first slice.
- Audio is synthesized with Web Audio; a later pass should add licensed field recordings.
- Browser smoke testing is currently Chromium-focused.
